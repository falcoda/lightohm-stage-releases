# Lightohm Stage

**Prévisualisation lumière en temps réel** pour Windows, Linux et macOS, par Falc'ohm et Gazmatek,
éditée par Coval Tech.

Ce dépôt sert uniquement à télécharger le logiciel. Présentation complète :
[falcohmsystem.com/lightohm-stage](https://falcohmsystem.com/lightohm-stage).

## Télécharger la dernière version

| Système | Fichier |
|---|---|
| Windows 10 et 11 (64 bits) | [Lightohm-Stage-Setup.exe](https://github.com/falcoda/lightohm-stage-releases/releases/latest/download/Lightohm-Stage-Setup.exe) |
| Linux x86_64 (Ubuntu 22.04 ou plus récent) | [Lightohm-Stage-Linux-x86_64.tar.gz](https://github.com/falcoda/lightohm-stage-releases/releases/latest/download/Lightohm-Stage-Linux-x86_64.tar.gz) |
| macOS 11 ou plus récent (Apple Silicon et Intel) | [Lightohm-Stage-macOS.dmg](https://github.com/falcoda/lightohm-stage-releases/releases/latest/download/Lightohm-Stage-macOS.dmg) |

Toutes les versions : [Releases](https://github.com/falcoda/lightohm-stage-releases/releases).

**Windows** : l'installateur n'est pas encore signé. Si Windows affiche « Windows a protégé
votre ordinateur », cliquez sur « Informations complémentaires », puis « Exécuter quand même ».

**Linux** : extrayez l'archive et lancez `./lightohm-stage`. Il faut une carte graphique
compatible Vulkan ; ffmpeg est conseillé pour les films. Voir `README-LINUX.txt` dans l'archive.

**macOS** : ouvrez le .dmg et glissez Lightohm Stage dans Applications. L'app n'est pas encore
notarisée par Apple : la première fois, faites clic droit sur l'app, puis « Ouvrir ». ffmpeg
(Homebrew) est conseillé pour les films. Voir `README-MACOS.txt` dans le .dmg.

Sans clé de licence, le logiciel fonctionne en version gratuite (2 univers DMX, une marque sur
les rendus et documents, 1080p). Pour une licence complète, contactez Falc'ohm System via le
site.
